# Project Shivodaya :: Earth Operations Control Center

Autonomous Ground Station and Telemetry Visualization Console for Project Shivodaya.

## Bundled Dependencies (No External Downloads Required)
- **`lib/flatlaf-3.5.2.jar` & `lib/flatlaf-3.5.jar`**: FlatLaf Dark Aerospace Look & Feel
- **`lib/sqlite-jdbc-3.45.1.0.jar`**: Pure Java/Native SQLite JDBC Driver
- **`parabitshivchaitanya.db`**: Pre-seeded telemetry SQLite database containing satellite tracking & interplanetary node classifications

## How to Build
```bash
./build.sh
```

## How to Run
```bash
./run.sh
```
Or from the project root:
```bash
./run_earth_control_center.sh
```
