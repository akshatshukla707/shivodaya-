# Project Shivodaya :: Earth Monitoring Center (Module 4)

Native C++17 telemetry query bridge and HTML5/WebGL visualization dashboard.

## Components
- **`earth_monitor.cpp`**: Native C++17 SQLite query engine polling Richa neural routing events.
- **`index_earth_dashboard.html`**: 3D interactive WebGL Earth operations monitoring dashboard.
- **`build.sh`**: Standalone compilation script using static SQLite3.
- **`run.sh`**: Launch runner for the query bridge.

## How to Build & Run
```bash
./build.sh
./run.sh
```
