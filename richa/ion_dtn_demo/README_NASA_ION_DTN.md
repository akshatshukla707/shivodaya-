# Project Shivodaya :: NASA ION DTN Loop Agent & Store-and-Forward Architecture

## Overview
This module integrates **NASA Interplanetary Overlay Network (ION)** Bundle Protocol v7 (RFC 9171 / BPv7) for deep-space store-and-forward communication across space mesh nodes.

Rather than relying on standard TCP/IP or UDP connections (which fail during planetary occultations and deep-space signal delays), this system uses **Store-and-Forward Custody Transfer**.

---

## 3-Terminal Demonstration Workflow

### **Terminal 1: NASA ION Sender (`ipn:1.1` - Aditya-L1 Solar Probe)**
- **Command**: `./richa/ion_dtn_demo/run_terminal1_sender.sh`
- Interactive CLI allowing the user to select and dispatch radiation alerts generated by Prakash (`prakash/warning_dispatch.txt`):
  1. `CME`
  2. `SEP`
  3. `Solar Wind`
  4. `X-Ray Flux`
  5. `Auto-Stream Batch`

### **Terminal 2: Online Receiver (`ipn:2.1` - Cis-Lunar Gateway Relay)**
- **Command**: `./richa/ion_dtn_demo/run_terminal2_receiver_online.sh`
- Opened **BEFORE** sending messages.
- Receives and prints incoming BPv7 radiation alert bundles live as they are dispatched from Terminal 1.

### **Terminal 3: Delayed Custody Receiver (`ipn:3.1` - Mars Operations Base)**
- **Command**: `./richa/ion_dtn_demo/run_terminal3_receiver_delayed.sh`
- Opened **AFTER** messages have already been sent and Terminal 1 is finished.
- Accesses non-volatile ION custody store-and-forward memory and displays stored bundles one by one with visual pacing (**0.8s per bundle**), demonstrating true DTN bundle preservation during communication blackouts.

---

## Technical Specifications
- **Protocol**: NASA ION BPv7 (RFC 9171)
- **Node Scheme**: `ipn` (Interplanetary Internet Naming Scheme)
- **Custody Memory**: Non-Volatile Store & Custody Signal ACK
- **Loop Agent**: NASA ION `lgagent` / `lgsend` Graph Architecture
