# Project Shivodaya :: DTN Store-and-Forward Architecture

## Overview
This module implements the **Project Shivodaya Deep Space DTN Engine** using Bundle Protocol v7 (RFC 9171 / BPv7) for deep-space store-and-forward communication across interplanetary space mesh nodes.

Rather than relying on standard TCP/IP or UDP connections (which fail during planetary occultations and deep-space signal delays), this system uses **Store-and-Forward Custody Transfer**.

---

## 3-Terminal Demonstration Workflow

### **Terminal 1: Shivodaya DTN Sender (`ipn:1.1` - ISRO Aditya-L1 Solar Probe)**
- **Command**: `./richa/ion_dtn_demo/terminal1sender.sh`
- Interactive CLI allowing the user to select and dispatch radiation alerts generated by Prakash (`prakash/warning_dispatch.txt`):
  1. `CME`
  2. `SEP`
  3. `Solar Wind`
  4. `X-Ray Flux`
  5. `Auto-Stream Batch (20 Multi-Radiation Bundles)`

### **Terminal 2: Online Receiver (`ipn:2.1` - Cis-Lunar Relay)**
- **Command**: `./richa/ion_dtn_demo/terminal2receiver.sh`
- Opened **BEFORE** sending messages.
- Receives and prints incoming BPv7 radiation alert bundles live as they are dispatched from Terminal 1.

### **Terminal 3: Delayed Custody Receiver (`ipn:3.1` - Mars Operations Station)**
- **Command**: `./richa/ion_dtn_demo/terminal3_delayed_receiver.sh`
- Opened **AFTER** messages have already been sent and Terminal 1 is finished.
- Accesses non-volatile DTN custody store-and-forward memory and displays stored bundles one by one with visual pacing (**0.8s per bundle**) alongside precise blackout delay latency calculations.

## Technical Specifications
- **Protocol**: Shivodaya Deep Space BPv7 (RFC 9171)
- **Node Scheme**: `ipn` (Interplanetary Naming Scheme)
- **Custody Memory**: Non-Volatile Store & Custody Signal ACK
- **Loop Agent**: Project Shivodaya Deep Space Mesh Graph Engine
